1这一课只做一件事：把链跑通

结论不追求效果好，只追求整条链通——注册、开机、装框架、喂数据、起训、拿 adapter、验一遍。全通了，后面每课都是在某一环上加码。
阶段这一步干什么卡住先看哪

把链跑通传数据 + 起训 + 看 loss + 推理 + 下载字段名对没对、loss 降没降
这一章钉住了三件事
  • 钉住了：这一课的目标是「链通」，不是「效果好」——别在第一版上抠参数
  • 不这么做会：一上来就想训全量 2 万条，光下载和数据预处理就把免费额度烧光
  • 下次遇到同类问题，先问：卡在哪一环——账号、环境、数据、命令，还是下载
带走第一遍只求「通」，不求「好」——链通了，后面每一课都在某一环上加码。

2注册领额度：手机号 + 绑阿里云

结论注册用手机号；免费 GPU 靠绑阿里云领——36 小时 A10 24G，够把这一课来回跑十几遍。
#动作做到什么算成
1手机号注册魔搭进 modelscope.cn，右上角注册，手机号收验证码，登录成功
2绑阿里云账号个人主页右下角「免费算力 待领取」→ 立即领取 → 用支付宝 / 钉钉扫码登录阿里云
3授权并领额度授权页所有选项全勾上，绑定成功后能看到「剩余 36 小时」

没有阿里云账号就当场注册一个，支付宝 / 钉钉 / 阿里云 App 都能扫码快速登录，不用单独记一套密码。

授权失败，九成是选项没勾全。魔搭要调用阿里云的算力，授权页的每个权限都得勾——漏一个，绑定就报「授权失败」，不是网络问题，回去把选项补全再点一次。

三条免费规则，先记在脑子里

规则会怎样这一课怎么应对
空闲 1 小时自动关不敲键盘就停，训练如果还挂着会被掐断训练一旦开跑，就让它跑，别离开太久
单次最长约 10 小时再长的训练会被强制停这一课 500 条只要十几分钟，够不着上限
36 小时用完就没了GPU 开不了，只能退回 CPU 环境配环境、传数据这类事，能不开 GPU 就不开
这一章钉住了三件事
  • 钉住了：免费 GPU = 手机号注册 + 绑阿里云 + 授权全勾
  • 不这么做会：授权漏勾、绑不上，卡在门口进不去
  • 下次遇到同类问题，先看：授权选项勾全没、剩余额度还剩多少
带走授权弹窗全勾上——这一处漏了，后面全白搭。

3开 Notebook、装 ms-swift

结论开一个 GPU 环境的 Notebook，镜像用默认（自带 torch 和 CUDA）；装 ms-swift 就一条 pip install，装完验 swift --help 有输出。

开 Notebook 到能敲命令

  1. 个人主页 → 「我的 Notebook」→ 创建，环境选 GPU（A10 24G）。
  2. 镜像保持默认（ubuntu + CUDA + torch），点启动，等 1–2 分钟变「运行中」。
  3. 「查看 Notebook」进 JupyterLab，打开一个 Terminal（终端）。
免费实例同一时间只能开一种。CPU 和 GPU 不能同时开着；高峰可能提示「免费资源已用满」，换个时间再试。开成功之前，别急着装任何东西。

开机第一件事：验证三行

python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
nvidia-smi
2.x.0+cu12x True
NVIDIA A10 ... 24GB

第一行 True、第二行认出 A10，说明驱动、CUDA、torch 对齐了。对不齐就换镜像，别修。

装 ms-swift，一条命令

pip install ms-swift -U
swift --help
usage: swift [-h] {sft,infer,export,web-ui,...} ...

第二行能打印出 sft、infer 这些子命令，就是装好了。装的过程几分钟，别以为卡死。

这一章钉住了三件事
  • 钉住了：开 GPU Notebook → 验三行 → 装 ms-swift → swift --help 有输出
  • 不这么做会：环境没验就装框架，后面报错都不知道是卡的问题还是包的问题
  • 下次遇到同类问题，先看：nvidia-smi 认不认卡、swift --help 出不出子命令
带走先验卡、再装框架——顺序反了，报错时你分不清是谁的锅。

4准备训练数据：一份 jsonl

结论训练数据是一个 jsonl，每行一对「口语问题 → 法条语体文本」。这一课用 500 条（从 DISC-Law 抽的），上传到 /mnt/workspace。

数据长什么样

# 每行一条 jsonl；query 是改写指令 + 口语问题，response 是法条语体文本
{
  "query": "请根据用户法律问题生成一段用于语义检索的假设性法律文档…\n\n用户问题：老板让我天天加班不给钱怎么办",
  "response": "《劳动法》第四十一条…延长工作时间…支付不低于工资的百分之一百五十…"
}

字段只认 query / response（也能写成 messages 那种对话格式）。名字写错，ms-swift 读不出样本，训练集就是空的。

这份 demo_hyde_500.jsonl 是本课附带的样例，从 DISC-Law Triplet 抽 500 条、已转好格式，直接上传即可。完整 2 万条怎么造、怎么洗，在 L05–L08 细讲。

三个字段怎么映射——改写的输入和输出
query
喂给模型的输入：一句「生成检索用文本」的指令，加上用户口语问题。模型要学的就是从这句话出发去改写。
response
期望的输出：一段带法条、法律概念、责任类型的书面文本。这就是「法条语体」，检索要命中的目标。
为什么不是问答
这一课训的是 HyDE 改写器，不是法律问答。输出是「拿来检索的文本」，不是「给用户的答案」。

把这份数据传上去

方式怎么做什么时候用
页面拖拽JupyterLab 左侧文件树，把 demo_hyde_500.jsonl 拖进 /mnt/workspace/文件只有几百 KB，最省事
scp 上传scp demo_hyde_500.jsonl root@实例:/mnt/workspace/文件大、要批量传
wget 拉取数据在网盘 / 对象存储上时，wget 直接拉数据托管在线上
# 传完在终端验一眼：行数、头一行
wc -l /mnt/workspace/demo_hyde_500.jsonl
head -n 1 /mnt/workspace/demo_hyde_500.jsonl
500 /mnt/workspace/demo_hyde_500.jsonl
{"query": "…", "response": "…"}
文件一定放在 /mnt/workspace。这是持久化盘，关机后数据还在；放别的地方，实例一停文件就没了，下次开机要重传。
这一章钉住了三件事
  • 钉住了：数据 = 每行一个 query/response 的 jsonl，放 /mnt/workspace
  • 不这么做会：字段名写错，ms-swift 读不出样本，训了个寂寞
  • 下次遇到同类问题，先 wc -l 数行、head 看字段名
带走数据就三个字——jsonl、query/response、持久化盘。

5一条命令起训

结论起训就是一条 swift sft，关键参数一只手数得过来：模型、数据、LoRA、量化、学习率、长度。其余照抄。
在 /mnt/workspace 下，一条命令起训（QLoRA）
swift sft \
  --model Qwen/Qwen3-1.7B \
  --tuner_type lora \
  --quant_method bnb --quant_bits 4 \
  --dataset /mnt/workspace/demo_hyde_500.jsonl \
  --torch_dtype bfloat16 \
  --num_train_epochs 3 \
  --per_device_train_batch_size 2 \
  --gradient_accumulation_steps 8 \
  --learning_rate 1e-4 \
  --lora_rank 16 --lora_alpha 32 \
  --target_modules all-linear \
  --max_length 1024 \
  --save_steps 50 --save_total_limit 2 \
  --logging_steps 10 \
  --warmup_ratio 0.05 \
  --output_dir /mnt/workspace/output/hyde_qwen3

首次跑会自动下载 Qwen3-1.7B（约 3GB），走魔搭内网几分钟下完。这一步不算卡死，是它在拉模型。

关键参数逐个过

参数这一课填什么为什么
--modelQwen/Qwen3-1.7B基座模型，魔搭官方仓库，内网直下
--tuner_type loralora只训补丁，不训整个模型
--quant_method bnb --quant_bits 4bnb + 4bit这两行合起来才是 QLoRA——基座压到 4bit，省显存
--dataset数据路径直接指到那份 jsonl
--num_train_epochs3500 条跑 3 遍，够看出 loss 下降趋势
--learning_rate1e-4LoRA 的常用档，比全参大一个量级
--max_length1024改写文本偏长，够装下；默认 2048 会浪费一半算力
--output_diroutput 目录checkpoint 落这，放持久化盘
起训前自检三句。① nvidia-smi 认到 A10；② wc -l 是 500；③ 命令里 --output_dir 在 /mnt/workspace 下。三句都过，回车。
bfloat16 要 GPU 支持。A10 支持，直接跑；如果换到很老的卡（算力 7.0 以下）会报 bf16 不支持的错，把 --torch_dtype 换成 float16 就行。
这一章钉住了三件事
  • 钉住了：QLoRA 两条参数——tuner_type lora 加 quant_method bnb + quant_bits 4
  • 不这么做会：漏了量化两条，就退回普通 LoRA，显存多占好几倍
  • 下次遇到同类问题，先看：模型下下来没、数据路径对不对、输出目录在不在持久化盘
带走QLoRA 就两条参数：lora 是方法，bnb + 4bit 是省显存——两个都写才叫 QLoRA。

6看 loss、拿 adapter

结论loss 一路往下、落到个位数，output 目录冒出 checkpoint，就算训成了。adapter 是几十 MB 的小文件，不是整个模型。

日志怎么读

{'loss': 2.83, 'learning_rate': 1.9e-05, 'epoch': 0.16}
{'loss': 1.87, 'learning_rate': 4.1e-05, 'epoch': 0.32}
{'loss': 1.42, 'learning_rate': 5.2e-05, 'epoch': 0.48}
{'loss': 1.15, 'learning_rate': 6.0e-05, 'epoch': 0.64}

只看一件事：loss 是不是一路往下。起点因基座和任务而异，但趋势必须往下、不再反弹，落到个位数（2 以下更稳）就算学到。

output 目录里有什么

/mnt/workspace/output/hyde_qwen3/
└─ v0-20261118-123456/        # 一次运行的编号目录
   ├─ checkpoint-50/          # 每 50 步存一个点
   │  ├─ adapter_config.json  # LoRA 配置
   │  └─ adapter_model.safetensors  # 补丁权重，几十 MB
   └─ logging.jsonl           # 完整 loss 记录

adapter_model.safetensors 就是这一课的成果，几十 MB；基座 3GB 不用下，adapter 要配着基座才能用。

断了怎么办：训练中实例被停或断连，用 --resume_from_checkpoint /mnt/workspace/output/hyde_qwen3/v0-.../checkpoint-50 重跑，会从那个点接着训，不是从头再来。
这一章钉住了三件事
  • 钉住了：看 loss 只看趋势，往下不反弹就算对；成果是 adapter 那个几十 MB 的小文件
  • 不这么做会：盯着 loss 绝对值较劲，或者把整个 3GB 模型当下载目标
  • 下次遇到同类问题，先看：loss 趋势、checkpoint 目录在不在
带走loss 看趋势不看绝对值，成果是几十 MB 的 adapter——不是那个 3GB 的基座。

7验它学会了

结论训完先 swift infer 喂一条口语问题，看它是不是真吐出了法条语体——吐得出来，才算学会；吐不出，这一课没交账。
swift infer \
  --model Qwen/Qwen3-1.7B \
  --adapters /mnt/workspace/output/hyde_qwen3/v0-.../checkpoint-100 \
  --infer_backend pt \
  --max_new_tokens 256 \
  --stream false

前后一对比，效果就出来了

时机输入一句口语输出应该长这样
训练前老板让我天天加班不给钱，怎么办答非所问，或直接给建议（改写器不该做这个）
训练后老板让我天天加班不给钱，怎么办一段带「延长工作时间」「百分之一百五十工资报酬」的法条语体文本
判断它学会的硬标准：喂口语，输出是「一段可以拿去检索的书面文本」，不是「给你的建议」。输出里带法条号、法律概念、责任类型，就对了。

把 adapter 下载到本地

# 在 Notebook 里打包，再从文件树右键下载；别下整个 3GB 模型
cd /mnt/workspace/output/hyde_qwen3
tar -czf hyde_adapter.tar.gz v0-.../checkpoint-100/

打出来的 hyde_adapter.tar.gz 几十 MB，下载秒完。这一课到这里，整条链走通了。

这一章钉住了三件事
  • 钉住了：验证就是喂口语、看输出，是不是变成了法条语体
  • 不这么做会：不验就打包，结果训歪了都不知道
  • 下次遇到同类问题，先喂一条最土的口语，看输出像不像法条
带走别急着庆祝，先喂一句口语——输出变成法条语体，才叫学会。

8小结

结论这一课交出去的是一条「能跑通」的链：账号有了、命令会敲了、adapter 到手了。剩下要做的，就是在这条链的每一环上，把 500 条换成 2 万条、把「通」换成「好」。

  • 验完再下载。不喂一句口语就打包，等于闭着眼交卷。
